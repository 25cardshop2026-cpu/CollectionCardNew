# Collection Card

เว็บฐานข้อมูลราคาการ์ดสะสม **One Piece** และ **Pokémon** พร้อมแดชบอร์ดหลังบ้านสำหรับเพิ่มการ์ดและอัปเดตราคา

> เฟส **P0** — หน้าเว็บสาธารณะและแดชบอร์ดใช้งานได้แล้ว แต่ยังทำงานบนข้อมูลตัวอย่างในหน่วยความจำ
> แผนเต็มและเหตุผลของการออกแบบอยู่ใน [`docs/PLAN.md`](docs/PLAN.md)

## เริ่มใช้งาน

```bash
npm install
npm run dev
```

เปิด http://localhost:3000

## หน้าที่มีแล้ว

| Route | ทำอะไร |
|---|---|
| `/` | เลือกเกม + การ์ดที่ราคาขยับแรง |
| `/g/[game]` | รายการชุดของเกมนั้น |
| `/g/[game]/[set]` | การ์ดทั้งหมดในชุด พร้อมตัวกรอง rarity และการเรียงลำดับ |
| `/card/[slug]` | รายละเอียดการ์ด ราคาแยก variant × สภาพ กราฟย้อนหลัง 90 วัน และ JSON-LD |
| `/movers` | การ์ดที่ราคาขยับแรงที่สุดใน 7 วัน |
| `/admin` | ภาพรวม จำนวนการ์ด และราคาที่ค้างอัปเดต |
| `/admin/prices` | ตารางอัปเดตราคาแบบ spreadsheet ทำงานด้วยคีย์บอร์ดล้วนได้ |

## โครงสร้าง

```
app/          หน้าเว็บทั้งหมด (App Router)
components/   ส่วนประกอบ UI ที่ใช้ซ้ำ
lib/types.ts  รูปร่างของข้อมูลทั้งระบบ
lib/seed.ts   ข้อมูลตัวอย่าง + ตัวสร้างราคาย้อนหลังแบบ deterministic
lib/repo.ts   ชั้นเข้าถึงข้อมูลทั้งหมด — จุดเดียวที่ต้องแก้ตอนต่อฐานข้อมูลจริง
docs/PLAN.md  แผนระบบฉบับเต็ม schema roadmap และข้อเสนอแนะ
```

## หลักการที่ยึดไว้ตั้งแต่ต้น

1. **ราคาผูกกับ variant + สภาพ ไม่ใช่ผูกกับการ์ด** — การ์ดใบเดียวกัน Normal กับ Alt Art ราคาต่างกันได้ 10–100 เท่า
2. **ภาษาเป็นอีกแกนหนึ่ง** — ชุดเดียวกันฉบับ JP กับ EN เป็นคนละแถวในตาราง `sets`
3. **บันทึกราคาเป็นแถวใหม่เสมอ ไม่เขียนทับ** — ประวัติราคาย้อนหลังซื้อกลับไม่ได้

## ขั้นตอนถัดไป

- [ ] ต่อ Postgres จริง แล้วเขียน adapter ใน `lib/repo.ts` (สัญญาของฟังก์ชันไม่ต้องเปลี่ยน)
- [ ] cron บันทึก snapshot ราคารายวัน
- [ ] รูปการ์ด — ตัดสินใจเรื่องลิขสิทธิ์ก่อน (ดู `docs/PLAN.md` ข้อ 6.13)
- [ ] Auth + คอลเลกชันของผู้ใช้ + % ความสมบูรณ์ของชุด

## ข้อจำกัดที่ต้องรู้

- **ข้อมูลเป็นตัวอย่าง** ชื่อการ์ดและราคาไม่ใช่ข้อมูลตลาดจริง ใช้เพื่อสาธิตโครงสร้างเท่านั้น
- **การแก้ราคายังไม่ถาวร** เก็บในหน่วยความจำของ process บน Vercel จะหายเมื่อ instance ถูกรีไซเคิล
- **`/admin` ยังไม่มีระบบ Auth** ต้องใส่ก่อนเปิดใช้งานจริง
